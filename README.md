# Analisis-Accidentes
Análisis de un dataset de accidentes en Colombia, se realiza un tratamiento de los datos y gráficas para contrastar con la realidad.
Se responden preguntas con respecto a la mortalidad basada en genero, edad, tipo de vehiculo, día de la semana, entre otros.

## Librerías usadas:
- Pandas
- Matplotlib
